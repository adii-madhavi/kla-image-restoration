# Model Card — KLA Restoration Candidate

## Overview

- **Task:** degraded (NoisyLR) grayscale image -> restored full-resolution
  grayscale image, for the KLA SEMICON India Hackathon 2026 problem
  statement "AI-Based Restoration of Degraded Images for Semiconductor
  Inspection".
- **Architecture:** `RestorationCandidate` (src/models/restoration_candidate.py)
  — residual-channel-attention blocks (RCAB) grouped into residual
  groups, pixel-shuffle 2x upsampling, global bicubic skip connection,
  optional frequency-domain branch (ablated, see docs/experiment_log.md).
- **Input:** single-channel grayscale, `128x128` or `256x256`, values
  may extend slightly outside `[0,1]`.
- **Output:** single-channel grayscale, `256x256` or `512x512`
  respectively, values in `[0,1]`.
- **Degradations handled (jointly, order-agnostic):** additive Gaussian
  noise, multiplicative speckle noise, spatial downsampling, and
  combinations thereof.

## Intended use

Restoring degraded semiconductor-inspection-style grayscale images for
the KLA Phase 1 benchmark. Trained on the officially supplied paired
GT/NoisyLR dataset (natural imagery per Phase 1 session guidance — see
Project.md §"Critical development clarification" — not physical
manufacturing defect data).

## Training data

- Source: official KLA-supplied paired dataset (path configured via
  `configs/final.yaml: data.degraded_dir / data.gt_dir`).
- Split: deterministic, seed 2026, `splits/split_seed_2026.json`
  (generated by `scripts/make_split.py`).
- Augmentation: paired-safe geometric flips/rotations; optional
  calibrated synthetic re-degradation from GT
  (`src/data/synthetic_degradation.py`), enabled per
  `configs/final.yaml: augmentation`.
- External data: see `docs/external_resources.md` (empty unless
  populated for this run).

## Known limitations

- Cannot recover information genuinely destroyed by degradation
  (irrecoverable information loss) — outputs are a regularized inverse
  estimate, not exact reconstruction (Project.md §"Reconciled technical
  interpretation").
- Quality on degradation combinations/severities far outside the
  training/augmentation distribution is not guaranteed.
- Hallucination risk: a restoration model can invent plausible-looking
  structure that was not present in the ground truth, which is
  particularly costly for defect-sensitive inspection use cases even
  though Phase 1 data itself contains no physical defects.
- Hidden-test score is unknown until KLA scores it; do not present ID
  validation numbers as a proxy for the hidden benchmark score.

## Reproducibility

```bash
python train.py --config configs/final.yaml
python inference.py --input_dir <input> --output_dir <output> \
    --config configs/final.yaml --weights weights/final.pt
```

Seed: `2026` (`configs/final.yaml: seed`). Git commit for this
checkpoint is recorded inside the checkpoint file itself
(`src/engine/checkpoint.py`).
